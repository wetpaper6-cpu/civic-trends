# 시민사회 동향

주요 시민사회단체의 기자회견·성명·논평을 자동으로 모아 정리하고, 사이트와 Releases에 올립니다.

- **단체:** 참여연대, 경실련, 한국노총, 민주노총, 환경운동연합, 녹색연합
- **키워드:** 청와대, 분수대, 기자회견, 성명, 논평
- **출처:** 네이버 뉴스 검색, 각 단체 홈페이지

## 게재 일정

| 요일 | 게재 내용 |
|---|---|
| 월·화·수 | 당일 동향 |
| 목 | 당일 동향 + **주간 동향**(직전 금요일~목요일, 7일) |
| 금·토 | 게재 없음 |
| 일 | 금~일 3일치 동향 |

일~목 오후 5시 17분에 시작하므로 보통 저녁 7시 전에 올라갑니다. GitHub 서버가 붐비면 시작이 조금 늦어질 수 있습니다.

## 양식

**일일 동향** (사안마다)

```
[기자회견] 제목
일시 / 장소 : 2026.11.18(수) 오전 11시 / 청와대 분수대 앞
주최 기관 : 참여연대, 민주노총
주요 내용 : …
```

성명·논평은 장소 없이 `일시`만 표시합니다.

**주간 동향** (A4 두 페이지 안팎)

1. 개요 (반 페이지)
2. 주요 정책/기조 현안 (한 페이지 이내)
3. 그 외 주요 쟁점 (반 페이지)
4. 참고자료: 표 (주요 쟁점 / 단위주체 / 핵심주장)

모든 동향은 사이트와 Releases에서 **Word·PDF**로 내려받을 수 있습니다.

## 필요한 키 (저장소 Settings → Secrets and variables → Actions)

| 이름 | 용도 |
|---|---|
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 네이버 뉴스 검색 |
| `ANTHROPIC_API_KEY` | 기사 정리와 주간 동향 작성 (Claude). 없으면 일일 동향은 단순 규칙으로 정리하고, 주간 동향의 1~3번은 통계로만 채웁니다 |

## 파일 구조

```
config.json                  단체·키워드·홈페이지 주소 설정
scripts/collect.py           일일 동향 수집·정리
scripts/weekly.py            주간 동향 작성 (목요일)
scripts/render.py            Word·PDF 생성
.github/workflows/daily.yml  자동 실행 일정
docs/                        사이트 (GitHub Pages)
```

단체나 키워드를 바꾸려면 `config.json`만 수정하면 됩니다.
